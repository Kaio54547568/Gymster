# Gymster Project Skill

Project type:
Gym management web application.

Core modules:
- Authentication and role-based access control
- Dashboard
- Gym room management
- Equipment management
- Staff management
- Member management
- Membership package management
- Payment and renewal tracking
- Training history
- Feedback management
- Revenue and statistics reports

User roles:
- Owner
- Manager
- Personal Trainer
- Member

Development rules:
- Prioritize MVP features first.
- Do not overbuild advanced features unless requested.
- Keep UI simple, clean, admin-dashboard style.
- Use reusable components for tables, forms, dialogs, filters, and status badges.
- Every CRUD module should include list, search/filter, create, update, delete or deactivate.
- Use role-based access control for protected pages.
- After changing code, explain changed files and how to test.
